3.1 新建项目

可通过多种方式创建新项目,本节主要介绍以不同的方式新建项目

3.1.1 起始页新建项目​

操作步骤：

  • 使用起始页新建项目
    • 首次打开时，将显示“起始页”，通过此页面可选择“新建项目”
  • 选择所要添加的设备（根据实际需要添加控制器或HMI）
    • 示例：控制器-->T4-->CPU-->T426E-->T426E-XEP-Z1-10（右侧有相关的设备简介）
    • 填写完成之后点击“确认按钮”完成创建
  • 填写相关信息
    • 名称（必填）：为项目进行命名
    • 路径（必填）：点击右侧“...”,选择存放的路径；或者直接在命令框中输入存放的路径（项目保存位置可以默认保存路径）
    • 作者（选填）：填写项目的负责人
    • 注释（选填）：为项目添加一注释，可以对项目进行一个简单的介绍
    • 填写完成之后点击“确认按钮”进入下一步

  • 在菜单栏新建项目

项目-->新建项目，以下步骤同“起始页新建项目”的第二步第三步
