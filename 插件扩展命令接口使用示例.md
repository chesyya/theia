# 插件扩展命令接口使用示例

本文档展示了如何使用Theia插件系统扩展的命令接口，该接口支持原生命令系统的显示隐藏和可用性控制机制。

## 功能概览

扩展的命令接口现在支持：

1. **可用性控制** (`isEnabled`) - 控制命令是否可用
2. **显示隐藏控制** (`isVisible`) - 控制菜单项是否显示
3. **切换状态控制** (`isToggled`) - 控制命令是否处于切换状态

## 接口定义

### CommandHandler 接口

```typescript
export interface CommandHandler {
    /**
     * 执行命令处理器
     */
    execute(...args: any[]): any;
    
    /**
     * 测试此处理器是否启用（可用）
     */
    isEnabled?(...args: any[]): boolean;
    
    /**
     * 测试此处理器的菜单项是否应该可见
     */
    isVisible?(...args: any[]): boolean;
    
    /**
     * 测试此处理器的菜单项是否应该被切换
     */
    isToggled?(...args: any[]): boolean;
}
```

## 使用示例

### 1. 基本扩展命令处理器

```typescript
import * as theia from '@theia/plugin';

// 注册一个带有可用性控制的命令
theia.commands.registerCommand(
    { id: 'my.extension.command', label: '我的扩展命令' },
    {
        execute: () => {
            theia.window.showInformationMessage('命令已执行！');
        },
        
        isEnabled: () => {
            // 只有在有活动编辑器时才启用
            return !!theia.window.activeTextEditor;
        },
        
        isVisible: () => {
            // 只有在JavaScript文件中才显示
            const editor = theia.window.activeTextEditor;
            return editor?.document.languageId === 'javascript';
        }
    }
);
```

### 2. 切换状态命令示例

```typescript
let toggleState = false;

theia.commands.registerCommand(
    { id: 'my.extension.toggle', label: '切换功能' },
    {
        execute: () => {
            toggleState = !toggleState;
            theia.window.showInformationMessage(`功能已${toggleState ? '启用' : '禁用'}`);
        },
        
        isToggled: () => {
            return toggleState;
        }
    }
);
```

### 3. 复杂条件控制示例

```typescript
theia.commands.registerCommand(
    { id: 'my.extension.conditional', label: '条件命令' },
    {
        execute: (context) => {
            // 执行基于上下文的逻辑
            console.log('在上下文中执行:', context);
        },
        
        isEnabled: (context) => {
            // 检查是否有必需的权限或状态
            return hasRequiredPermissions() && isValidContext(context);
        },
        
        isVisible: (context) => {
            // 基于用户角色或设置决定是否显示
            return getUserRole() === 'admin' || isFeatureEnabled('advanced-features');
        },
        
        isToggled: (context) => {
            // 基于某些状态返回切换状态
            return getCurrentMode() === 'debug';
        }
    }
);
```

### 4. 与MCP系统集成示例

```typescript
// 类似MCP命令的扩展命令注册
function createMCPLikeCommand(toolName: string, toolConfig: any) {
    return theia.commands.registerCommand(
        { id: `mcp.tool.${toolName}`, label: `MCP: ${toolConfig.displayName}` },
        {
            execute: async (...args) => {
                // 执行MCP工具逻辑
                return await executeMCPTool(toolName, args);
            },
            
            isEnabled: () => {
                // 检查MCP服务器是否可用
                return isMCPServerRunning(toolConfig.serverName);
            },
            
            isVisible: () => {
                // 基于用户配置决定是否显示MCP工具
                return isToolVisible(toolName);
            }
        }
    );
}
```

## 兼容性说明

1. **向后兼容**: 现有的简单函数形式的命令处理器仍然完全兼容：
   ```typescript
   // 这种写法仍然有效
   theia.commands.registerCommand('old.command', () => {
       console.log('旧式命令处理器');
   });
   ```

2. **类型安全**: TypeScript会自动推断命令处理器的类型，提供完整的类型检查支持。

## 实现原理

### 架构概览

```
插件侧 (Plugin Side)                    主进程侧 (Main Side)
┌─────────────────────────┐             ┌─────────────────────────┐
│ CommandRegistryImpl     │<----RPC---->│ CommandRegistryMainImpl │
│ - registerCommand()     │             │ - $registerExtended...  │
│ - isExtendedHandler()   │             │ - extendedCapabilities  │
│ - $checkEnabled()       │             │                         │
│ - $checkVisible()       │             │                         │
│ - $checkToggled()       │             │                         │
└─────────────────────────┘             └─────────────────────────┘
             │                                         │
             v                                         v
┌─────────────────────────┐             ┌─────────────────────────┐
│ ExtendedHandler         │             │ PluginContributionHandler│
│ - execute()             │             │ - registerCommandHandler│
│ - isEnabled?()          │             │ - CommandHandler support│
│ - isVisible?()          │             │                         │
│ - isToggled?()          │             │                         │
└─────────────────────────┘             └─────────────────────────┘
```

### 关键组件

1. **ExtendedHandlerCapabilities**: 描述扩展处理器的能力
2. **CommandRegistryExt**: 插件侧的RPC接口扩展
3. **CommandRegistryMain**: 主进程侧的RPC接口扩展

## 最佳实践

1. **性能考虑**: `isEnabled`、`isVisible`、`isToggled` 方法会被频繁调用，应避免复杂计算
2. **异步处理**: 这些方法目前支持同步返回，避免使用Promise
3. **错误处理**: 在这些方法中应避免抛出异常，返回合理的默认值
4. **状态管理**: 对于切换状态，建议维护清晰的状态管理机制

## 总结

通过这个扩展接口，插件开发者现在可以：
- 创建更智能的命令，根据上下文动态控制可用性
- 实现更好的用户体验，只在相关时显示命令
- 支持切换状态的命令，类似原生IDE功能
- 与现有Theia命令系统完全集成，享受所有原生功能
